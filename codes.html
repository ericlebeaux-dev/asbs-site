NIGP codes

NIGP codes classify commodities and services on many state and local solicitations. The NIGP Commodity/Services Code is copyrighted by NIGP and licensed to Periscope Holdings. This website does not copy the class list or the class-item list. Look up the official description, then type the code on the intake form.
