NAICS and NIGP codes

NAICS codes are the federal industry classifications published by the U.S. Census Bureau. The list below is every 2022 six-digit code. Open a sector or search. Using a code here does not register a business, and it does not start paid work.

NIGP codes

NIGP codes classify commodities and services on many state and local solicitations. The NIGP Commodity/Services Code is copyrighted by NIGP and licensed to Periscope Holdings. This website does not copy that list. Look up a code, then type it on the intake form. A code saved there is part of the intake. It is not an application to any agency.
